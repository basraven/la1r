Make a bash script that uses the cloud-backup-media-config.yml structure as inputs and then do the following:
1. find all files and folders in the spec.sources.path directory and zip not the deepest folder, but the deepest folder -1, that contains the files and folders
2. Make sure that all files in the spec.sources.exclude list are excluded from the zip file.
3. Do the zipping of the prevous step with 7zip if spec.compression.type is 7zip, otherwise use tar.gz. If the compression.type is 7zip, then use the compression.arguments as arguments to 7zip, otherwise use the compression.arguments as arguments to tar.gz.
4. Then encrypt the zip file with gpg. If the encryption.type is gpg.
5. Store the encrypted files in the spec.sources.target directory.
6. If the spec.sources.target directory does not exist, create it.
7. If the spec.sources.target directory is not empty, delete all files and folders in the directory.
8. Provide a dry run option to the script.
9. Now also create a single .json file that contains an md5 hash of the entire contents of the 'to zip' folders (before zipping and encrypting). Store the hash in the .json file together with the path so it can later be used to detect changes in the folder.
10. As final summary give a amount of bytes that have changed comparing the last .json file to the current state. 
11. Finally save the new .json file in the root directory
12. It should be able to handle multiple sped.sources
13. If you use any dependencies, then make sure there is a check for those dependencies and if they are not installed, then stop the script with an error message.
14. When using yq, then use the Python3 version of yq.
15. Try to reduce dependencies by using common linux commands.

# cloud-backup-media-config.yml
---
apiVersion: backup.la1r.com/v1
kind: cloudbackup
metadata:
  name: cloudbackup-media
spec:
  compression: 
    type: 7zip
    arguments: -m0=lzma2 -mx=9
  encryption:
    type: gpg
  sources:
    - name: "basraven" # label of source, does not need to be used
      path: "/home/basraven/projects/la1r/kubernetes/backup/media" # path can be relative or absolute
      target: "/home/basraven/projects/la1r/kubernetes/backup/media-zipped" # path can be relative or absolute
      excludes: # relative path to exclude
        media/top_3/folder_3013/folder_4589_notme
